# Автоматические проверки аналитических SQL-запросов

Из каталога `Sprint2/test` выполните:

```bash
make query-check
```

Команда пересоздаёт только тестовую БД `service_center_test`, применяет миграции,
загружает базовые и дополнительные тестовые данные, запускает каталог
`queries/business_queries.sql` и проверяет ожидаемые результаты восьми запросов.

Проверки охватывают:
1. выборку заявок по статусу;
2. выборку выполняющихся ремонтов;
3. активные резервы запчастей;
4. агрегирование заявок по клиентам;
5. суммы оплаченных заявок;
6. рейтинг мастеров;
7. помесячную динамику с `LAG` и накопительным итогом;
8. историю статусов с `LEAD`.

Если хотя бы одна проверка завершается неуспешно, SQL-скрипт вызывает ошибку,
а `make` возвращает ненулевой код завершения.

Можно задать другое имя тестовой БД и параметры подключения:

```bash
make query-check TEST_DB=my_service_center_query_test PSQL_HOST=localhost PSQL_PORT=5432 PSQL_USER=my_user
```

**Внимание:** цель `query-check` удаляет и создаёт заново только базу,
указанную в `TEST_DB`. Не указывайте в `TEST_DB` рабочую базу `service_center`.
